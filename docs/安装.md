# 安装

运行环境：

- Java 21
- Paper 1.21.4
- Vault 和一个可用的经济插件
- BKCommonLib、My_Worlds、FastAsyncWorldEdit、RookieRegions 2.0.0+、ModelEngine R4.0.9
- 可选：PlaceholderAPI、PlayerPoints、EssentialsChat

将 `RookieCityState.jar` 放入服务端 `plugins` 目录后启动服务器。

默认发布包会在 `citystate_template` 不存在时自动安装内置 Java 1.21.4 城堡岛，并设置
512 格边界与 RookieRegions `city_core`；已有同名世界不会被覆盖。自定义模板的准备步骤见
[独立城邦世界部署手册](CITY_WORLDS.md)。

首次启动后执行 `/meg reload models` 并部署 ModelEngine 生成的资源包。完整步骤见 [城邦公共灵兽 V1](GUARDIAN_BEAST.md)。
