# 配置

配置目录为 `plugins/RookieCityState/config`：

- `settings.yml`：所有通用设置均位于 `city_state.*`。
- `lang.yml`：玩家提示文本。
- `gui/*.yml`：城邦 GUI。
- `shop/*.yml`：商店与奖励。
- `defaults/`：只读默认配置参考。

数据目录：

- `data/city_states`：城邦数据。
- `data/players`：玩家数据。
- `data/requests`：请求数据。

GUI 模板变量统一使用 `{city_state_*}`。商店城邦奖励类型为 `CITY_STATE_SET_SPAWN`、`CITY_STATE_UPGRADE`、`CITY_STATE_TP_ALL`、`CITY_STATE_SHOP` 和 `CITY_STATE_ICON`。

`/citystate plugin reload` 会先构建并校验完整配置快照；失败时继续使用上一份有效配置。无效 GUI 装饰显示为 BARRIER，无效商店奖励会禁用对应商品。
