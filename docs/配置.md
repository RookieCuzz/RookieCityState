# 配置

配置目录为 `plugins/RookieCityState/config`：

- `settings.yml`：所有通用设置均位于 `city_state.*`。
- `lang.yml`：玩家提示文本。
- `gui/*.yml`：城邦 GUI。
- `shop/*.yml`：商店与奖励。
- `wish_tree_rewards.yml`：许愿奖池、品质保底、概率与四档周奖励。
- `guardian_beast.yml`：公共灵兽成长、食物、模型和交互参数。
- `guardian_shop.yml`：灵兽贡献商品、周轮换、粒子和动作参数。
- `city_social.yml`：参观资格、每周票数、热门窗口、权重和社交明细保留时间。
- `defaults/`：只读默认配置参考。

数据目录：

- `data/city_states`：城邦数据。
- `data/players`：玩家数据。
- `data/requests`：请求数据。
- `data/operations`：可恢复的创建、支付和解散操作日志。
- `data/archives`：解散后保留的世界归档。
- `data/wish_trees`：城邦许愿树等级、经验和周进度。
- `data/operations/wish-tree`：可恢复的 FAWE 升级与回滚记录。
- `data/guardian_shop/rotations`：全服统一的灵兽贡献商店周轮换快照。
- `data/social/cities`：每个城邦的合格参观、点赞和历史总赞。
- `data/social/errors`、`data/quarantine/social`：损坏社交文件的错误标记与隔离副本。

GUI 模板变量统一使用 `{city_state_*}`。商店城邦奖励类型为 `CITY_STATE_UPGRADE`、
`CITY_STATE_TP_ALL`、`CITY_STATE_SHOP` 和 `CITY_STATE_ICON`。旧配置中的
`CITY_STATE_SET_SPAWN` 仍可解析，但会显示为不可购买的 BARRIER。

`city_state.world.*` 与模板准备方式见 [独立城邦世界部署手册](CITY_WORLDS.md)。
`city_state.world.bundled_template.enabled` 控制是否在模板缺失时安装内置城堡岛；
`city_state.world.core_bounds` 仅用于首次安装内置模板时创建 `city_core`。内置模板已经包含主城，
因此 `city_state.wish_tree.schematics.main.enabled` 默认为 `false`。

`/citystate plugin reload` 会先构建并校验完整配置快照；失败时继续使用上一份有效配置。无效 GUI 装饰显示为 BARRIER，无效商店奖励会禁用对应商品。
