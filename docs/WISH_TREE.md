# 城邦许愿树 V1

玩家可在“我的城邦”或城邦世界的树前交互实体打开界面。每日 04:00
（`Asia/Shanghai`）重置：首次许愿免费，之后最多使用 5 颗魔力石额外许愿。
每次许愿都产生基础奖励，并累计当前品质心愿的 30/80 次保底。

每周一 04:00 开启新周期。成员每日可浇水一次，四档进度解锁后不会因参与人数
增加而回锁。入邦满 72 小时且本周浇水至少 3 次才可手动领取周奖励。

## 结构与修订

首次启动会在 `plugins/RookieCityState/schematics` 生成主城和 1～5 级树的极简占位
`.schem`。当前修订会复制到 `data/schematic_snapshots/<template_revision>` 并生成 SHA-256
清单。要替换结构，必须同时提升 `city_state.world.template_revision`；已有城邦仍使用旧快照。

五个树结构必须都是 `15×24×15`，原点和边界一致，并包含空气。升级会先备份当前
区域；粘贴、世界保存或提交失败时自动回滚。重启时会扫描
`data/operations/wish-tree` 并继续回滚未完成操作。

## 奖励箱

奖励先以完整快照进入玩家 YAML，不会因配置重载而改变。待领取上限为 200，且不过期。
外部经济、点券或指令发放期间服务器中断时，记录会进入 `AMBIGUOUS`，只能由管理员
明确标记已发放或恢复重试，插件不会猜测或重复发放。
