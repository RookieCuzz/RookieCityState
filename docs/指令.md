# 命令

主命令为 `/citystate`，别名为 `/cs`。

- `/citystate gui main`：玩家打开城邦主界面。
- `/citystate plugin version`：显示插件版本。
- `/citystate plugin reload`：原子重载配置，需要 `rookiecitystate.admin`。
- `/citystate logger debug`：切换 DEBUG/INFO 日志，需要管理员权限。
- `/citystate helper getItemInfo`：显示手中物品的 material 和 damage，需要管理员权限。
- `/citystate world exit`：离开当前城邦或恢复世界。
- `/citystate world status|load|unload|provision <城邦>`：查看、加载、卸载或免费补建城邦世界。
- `/citystate world reconcile`：重试未完成的世界操作。
- `/citystate archive list|restore <归档ID>`：列出或恢复解散地图。
- `/citystate recovery unload|delete <世界>`：管理只供管理员使用的恢复世界。
- `/citystate operation list`：查看未完成或待人工核对的操作。
- `/citystate operation resolve <ID> charged|not_charged`：确认异常支付结果。
- `/citystate wishtree status city <城邦|UUID>`：查看树等级、建筑状态与周进度。
- `/citystate wishtree status player <玩家|UUID>`：查看魔力石、保底和异常奖励。
- `/citystate wishtree reset weekly|level|daily|pity ... confirm`：备份后重置指定数据。
- `/citystate wishtree grant stones|reward ...`：补发魔力石或配置奖励。
- `/citystate wishtree claim resolve <玩家> <claimId> delivered|retry`：人工核对不确定发放。
- `/citystate wishtree visual retry <城邦>`：重试树建筑维护。
- `/citystate guardian status city <城邦|UUID>`：查看种类、形态、等级、完成日和每日饱食。
- `/citystate guardian status player <玩家|UUID>`：查看玩家可用/累计贡献与今日喂养次数。
- `/citystate guardian reset daily|species <城邦> confirm`：备份并重置城邦灵兽数据。
- `/citystate guardian set days <城邦> <0-53> confirm`：设置累计喂满日并刷新外观。
- `/citystate guardian grant contribution <玩家> <数量>`：补发可用与累计贡献。
- `/citystate guardian visual retry <城邦>`：重试实体与模型外观。
- `/citystate guardian models status|install`：校验或补装七个 ModelEngine 蓝图。
- `/citystate guardian shop status [player <玩家>]`：查看轮换或玩家商店状态。
- `/citystate guardian shop rotate confirm`：立即生成并保存新轮换。
- `/citystate guardian shop grant product <玩家> <商品ID>`：补发永久商品。
- `/citystate guardian shop revoke product <玩家> <商品ID> confirm`：备份后撤销永久商品并卸下。
- `/citystate guardian shop reset limits <玩家> confirm`：备份后清空玩家周限购记录。
- `/citystate social hot`：打开公开城邦热门榜。
- `/citystate social status city <城邦|UUID>`：查看城邦热度、访客、点赞和数据状态。
- `/citystate social status player <玩家|UUID>`：查看玩家本周票数、资格和点赞记录。
- `/citystate social vote revoke <城邦> <玩家> <weekCycle> confirm`：备份并撤销指定周点赞。
- `/citystate social reset recent|all <城邦> confirm`：备份并重置近期或全部社交数据。
- `/citystate social rebuild`：从磁盘重建社交索引和热门榜。

无参数或参数错误时会显示上下文帮助。

除 `world exit` 外，世界管理命令均需要 `rookiecitystate.admin`。
