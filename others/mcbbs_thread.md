# RookieCityState

RookieCityState 是面向 Paper 1.21.4 / Java 21 的现代城邦插件，提供创建、成员审批、权限管理、城邦银行、商店、主城、全员集结、PVP 控制、GUI 与占位符。

## 依赖

- 必需：Vault 和经济插件
- 可选：PlaceholderAPI、PlayerPoints、EssentialsChat

## 使用

- 主命令：`/citystate`
- 别名：`/cs`
- 管理权限：`rookiecitystate.admin`
- 彩色城邦名权限：`rookiecitystate.create.colored`

成品为 `target/RookieCityState.jar`。
